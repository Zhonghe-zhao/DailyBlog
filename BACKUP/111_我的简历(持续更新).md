## 项目经历

### MemoBridge｜本地知识理解与交付工作台｜个人项目  `2026.01-至今`

MemoBridge 是面向长期学习与项目研究的认知状态管理系统，以主题知识空间组织资料，以持续探究问题承载用户的思考、当前理解和下一步，并将状态稳定交付给新的用户或 AI 会话。

- 针对资料措辞与用户查询表达不一致、单一检索通道容易漏召回的问题，基于 PostgreSQL pg_trgm 与 pgvector 构建词法、语义档案、向量片段和已确认关系的混合召回链路，采用确定性切片、本地 bge-m3 生成向量并通过 RRF 融合异构排名；在 12 条人工查询中将 Recall@10 从 29.17% 提升至 68.06%，MRR 从 21.88% 提升至 32.62%，并支持向量服务失败时降级保留非向量结果。
- 面向持续研究问题构建受控 RAG，将用户主动组织的资料、已确认理解与同一主题知识库的动态召回证据结合，设计仅资料、协作回答和开放探索三种证据边界；模型返回后由服务端校验引用资料 ID 与原文片段，过滤越界或伪造引用，避免模型将外部知识包装成本地资料。
- 将每次模型交互持久化为有状态调用记录，通过客户端请求 ID 实现重试幂等，记录执行状态、模型、Token、延迟及上下文/检索快照；提供无模型调用的 Prompt 预览、问题级诊断接口与 Prometheus 指标，并在请求取消或模型失败后可靠收口调用状态。
